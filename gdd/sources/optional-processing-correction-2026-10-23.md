# Optional processing clarification — 2026-10-23

Direct user correction, copied verbatim:

> ikke alt tekst skal bearbejdes

Accepted clarification: text processing is optional. A dictation can proceed from
speech recognition directly to delivery and history without cleanup or rewriting.
An unprocessed result has one text representation, not an artificial raw/final pair.
This does not choose raw or cleanup as the default mode, nor answer whether both
versions should be persisted when processing actually takes place. That retention
choice remains open. Earlier wording describing light cleanup in the first release
means availability of optional cleanup, not mandatory processing of every result.
