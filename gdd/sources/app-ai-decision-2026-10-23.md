# App-specific automatic AI — 2026-10-23

Direct user answer, copied verbatim:

> Ja, jeg vil kunne slå AI-bearbejdning fast til for en bestemt app, så den automatisk bruger appens prompt. Ellers direkte transskription som standard.

Accepted: an explicit per-app enable setting makes that app’s AI prompt run
automatically on dictations invoked there. Otherwise direct transcription remains
the default. A prompt merely existing is not the enable setting. Resolve the app
at invocation, not from later foreground focus. General prompts remain available
for explicitly requested optional processing, not an implicitly enabled global
rewrite. Local/cloud permission is separate from app-level AI activation.

Whether transformed output should be automatically inserted under the existing
focus rules or previewed for confirmation is a separate unresolved interaction.
