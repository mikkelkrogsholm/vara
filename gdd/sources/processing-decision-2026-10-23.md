# Processing default — 2026-10-23

Direct user answer, copied verbatim:

> Begge dele, men lokalt som standard. Det skal være nemt at komme i gang, og man skal kunne vælge cloud, hvis man foretrækker det.

Accepted direction: support both local and cloud processing in the first-release
core workflow. Default to local processing, with approachable setup. Cloud is an
explicit user choice rather than a silent fallback. This applies to speech and
optional text processing, which must be presented separately and clearly.

Cloud provider, accounts, access/payment mechanism, model choice, download size
and exact supported hardware remain undecided. No managed cloud service is
implicitly commissioned by this decision.
