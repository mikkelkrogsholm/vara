# Repository English reconciliation

The current documentation, prototype, runtime defaults and editable design were reconciled in November 2026. English is the current presentation language; Danish remains a supported app locale. Current design references and exports were refreshed, while the original mockups, source records and historical evidence were retained. The Figcraft audit covered 31 frames, 33 components, 54 instances and 1,375 text layers; no missing fonts were reported. This is not a claim of exact pixel parity or of zero Danish bytes.

Danish deliberately remains in the `da` catalogs and native localization, startup fallback, compatibility labels for saved settings, Danish speech/Unicode and migration fixtures, original quotations, observed native labels, measured transcripts and historical screenshots. Those strings serve product functionality, regression coverage or evidence. The audit searched tracked human-facing Markdown, HTML, JavaScript, JSON, SVG and editable design text for Danish words (including ASCII spellings), not just Danish-specific characters. Inspection is sampling and keyword based, not proof that every possible phrase was detected.
