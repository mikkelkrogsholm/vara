# Indstillinger v2 — imagegen-mockups

Visuel udforskning, 2026-10-24. Samme Warm precision-retning som den valgte
første mockup. Brugerens godkendelse og implementeringsregler er nu indarbejdet
i ../../../DESIGN.md. Mockup-værdier ændrer ikke brugerens gemte indstillinger.

- [Diktering](01-diktering.png): optagelse, talemodel og valgfri AI-bearbejdning samlet.
- [Modeller og nøgler](02-modeller-og-noegler.png): lokale downloads, API-nøgler og adgangstest.
- [Privatliv](03-privatliv.png): lokal/cloud-behandling, historik og faste regler for lyd.

Første mockup viser bevidst AI slået til, så tekstmodel og instruktioner kan vurderes.
Direkte transskription er fortsat produktets standard. Modelnavne, statusser og
valgte værdier er illustrationer, ikke ændringer af brugerens opsætning.

Privatlivssiden viser lydpolitikker som forklaringer med ikoner, ikke som justerbare
indstillinger. Endelig produktionstekst, kontrolstørrelser og tilgængelighed skal
følge DESIGN.md og gennemgås ved en eventuel implementering. Genererede billeder
er ikke en ny autoritativ komponent- eller adfærdskontrakt.

Reference: ../01-warm-precision.png og ../../../DESIGN.md.
